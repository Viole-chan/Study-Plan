# Study Plan

This repository will serve as the basis for a mobile app designed for:
- Scanning notes and photos.
- OCR text extraction and summaries.
- Note-taking and flashcard creation.
- A timetable generator.
- Text-to-speech functionality.

Features will include support for:
- Dark and Light mode.
- Customizable reading directions (left-to-right or up-and-down).
- Syncing data across devices.
